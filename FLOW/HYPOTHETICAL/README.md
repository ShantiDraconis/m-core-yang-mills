# HYPOTHETICAL flow

Counterfactual research only.

Allowed:
- assume a zero off the critical line and trace consequences;
- assume a multi-state number/object and saturate its algebra;
- toy/countermodels;
- closure-oracle experiments;
- dependency sensitivity analysis.

Required marking:
`hypothetical=true`.

Forbidden:
- import into REAL terminal proof paths;
- GREEN/FROZEN/CERTIFIED promotion;
- claiming a conjecture/proposition is proved;
- turning a hypothetical assumption into a production rule.
